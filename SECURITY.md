# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately — do not open a public issue.

- Email: dev@brandazine.com
- Include: the affected component (CLI version from `solari --version`, connector, or plugin), reproduction steps, and impact.

We will acknowledge reports as quickly as we can, typically within a few business days.

## Scope

- `solari` CLI release binaries distributed through this repository
- The SOLARI connector at `solari.sh`
- The Claude Code plugin in this repository

## Out of scope

- Denial of service through volumetric traffic
- Findings that require a compromised user machine or stolen credentials
